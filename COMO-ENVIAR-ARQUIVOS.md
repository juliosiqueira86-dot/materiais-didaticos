# Como enviar arquivos manualmente (pelo site do GitHub)

Não precisa instalar nada: tudo é feito no navegador, logado na conta **juliosiqueira86-dot**.

## Enviar arquivos para uma pasta que já existe

1. Abra <https://github.com/juliosiqueira86-dot/materiais-didaticos> e entre na pasta desejada
   (ex.: `UERJ` → `2026.2` → `Estatistica-Computacional` → `materiais-suplementares`).
2. Clique em **Add file** → **Upload files**.
3. Arraste os arquivos para a página (ou clique em **choose your files**).
4. Em **Commit changes**, escreva uma frase curta (ex.: "Adiciona lista 1").
5. Deixe marcado **Commit directly to the main branch** e clique em **Commit changes**.

## Criar uma pasta nova (ex.: nova disciplina ou novo período)

O GitHub não guarda pastas vazias: a pasta é criada junto com o primeiro arquivo.

1. Entre na pasta "mãe" (ex.: `FGV`).
2. Clique em **Add file** → **Create new file**.
3. No nome do arquivo, digite o caminho com barras, por exemplo: `2027.1/Estatistica-I/README.md`
   (cada `/` cria uma pasta).
4. Escreva uma linha de descrição no conteúdo e clique em **Commit changes**.
5. Depois, entre na pasta criada e use **Add file** → **Upload files** para enviar os PDFs.

## Substituir um arquivo por uma versão nova

Envie o arquivo com **o mesmo nome** pelo **Upload files**: o GitHub substitui a versão anterior
(a antiga continua no histórico).

## Apagar um arquivo

Abra o arquivo, clique nos três pontinhos (**⋯**) no canto superior direito e em **Delete file**,
depois em **Commit changes**.

## Boas práticas

- Nomes de arquivos e pastas sem acentos e sem espaços (use hífen): os links ficam mais limpos.
- Limite do site: 25 MB por arquivo no envio pelo navegador.
- O repositório é **público**: não envie listas de alunos, notas, frequências ou qualquer dado pessoal.
- Só envie obras de outros autores com autorização ou licença que permita redistribuição.
